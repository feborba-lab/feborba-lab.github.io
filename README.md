# Portfólio — Fernando Borba

Site pessoal feito em HTML, CSS e JavaScript puro, sem framework e sem etapa de build.

- Em português e inglês (botão PT/EN no topo, ou `?lang=en` no link).
- Console de SQL que roda no navegador (SQLite via sql.js) sobre um pipeline de vendas **fictício**.
- Demo de validação de discovery para CRM com dados **fictícios**.

Para rodar localmente, basta abrir o `index.html` no navegador.
